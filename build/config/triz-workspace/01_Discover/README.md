# Phase 01: Discover

## Objective
Identify the problem space through prior-art search, paper/patent discovery, and stakeholder analysis.

## Key Activities
- Run `/search` to discover papers and patents
- Run `/init` to initialize research context
- Document findings in `papers.json` / `patents.json`
- Use the AI chat to analyze search results

## Deliverables
- `papers.json` — curated paper references
- `patents.json` — relevant patent landscape
- `search_queries.md` — search strategy and results
- Problem statement and scope definition
