# TRIZ Research Project

This is a **TRIZ Research Project (TRP)** workspace for Trinno Research IDE.

## Project Phases

| Phase | Directory | Description |
|-------|-----------|-------------|
| 01 | `01_Discover/` | Prior-art search, paper/patent discovery, problem identification |
| 02 | `02_TRL/` | Technology Readiness Level assessment, S-curve analysis |
| 03 | `03_Analyze/` | Contradiction analysis, Su-Field analysis, bottleneck identification |
| 04 | `04_Synthesize/` | Solution generation, ideality evaluation, principle application |
| 05 | `05_Deliver/` | Final reports, presentations, documentation |
| 06 | `06_References/` | Reference papers, patents, resources |
| 07 | `07_Patent/` | Patent drafting and disclosure preparation |
| 08 | `08_TData/` | Test data, experiments, validation evidence |

## Getting Started

1. Open the Research Assistant panel (Cmd+Shift+C)
2. Run `/init` to initialize your research context
3. Run `/search` to discover prior art
4. Follow the guided 7-phase workflow

## Settings

TRIZ-optimized settings are pre-configured in `.vscode/settings.json`.
